KRS Course Enrollment Automation

Skrip untuk mengotomatisasi pengisian Kartu Rencana Studi (KRS) di Universitas Airlangga menggunakan Python dan Selenium[cite: 6].

Python Selenium Pandas Numpy Automation

Latar Belakang & Tujuan

Proyek ini dirancang untuk membantu mahasiswa Universitas Airlangga mengotomatisasi proses pengisian Kartu Rencana Studi (KRS) secara cepat dan efisien[cite: 6].

Skrip ini memanfaatkan Python dan Selenium untuk berinteraksi dengan portal mahasiswa, yang bertujuan untuk mengamankan kelas mata kuliah selama periode pengisian KRS yang padat dengan menawarkan mode eksekusi manual dan otomatis[cite: 6].

Pendekatan Teknis & Fitur

Program ini dibangun menggunakan Python, memanfaatkan pustaka Selenium bersama dengan ChromeDriver untuk mengotomatisasi interaksi peramban (browser)[cite: 6]. Program ini juga memanfaatkan Pandas dan Numpy untuk menangani data latar belakang secara efisien[cite: 6].

Fitur Otomatisasi Utama

  • Login & Validasi Otomatis: Memiliki fitur login otomatis ke portal mahasiswa Universitas Airlangga dan memvalidasi pengguna melalui Google Spreadsheet[cite: 6].
  • Mode Manual: Mengeksekusi proses pendaftaran pada waktu yang spesifik dan tepat (jam, menit, dan detik) saat registrasi KRS resmi dibuka[cite: 6].
  • Mode Otomatis: Memeriksa secara berkala dan mengulang proses pendaftaran hingga semua mata kuliah yang ditargetkan berhasil didaftarkan[cite: 6].

Penggunaan & Konfigurasi

Skrip ini dirancang agar sangat mudah dikonfigurasi melalui file teks eksternal, memungkinkan mahasiswa mempersiapkan target mereka sebelum masa pendaftaran dimulai[cite: 6]:

  • Pengguna hanya perlu memasukkan kredensial dan mata kuliah target mereka ke dalam file spesifik: nim.txt, pw.txt, matkul.txt, dan kelas.txt[cite: 6].
  • Program memberikan output status yang jelas (berhasil atau gagal) untuk setiap percobaan pendaftaran[cite: 6].
  • Demonstrasi video untuk mode Manual maupun Otomatis telah direkam dan didokumentasikan di YouTube untuk memandu pengguna baru melalui proses eksekusi[cite: 6].

Peringatan: Skrip ini dibuat secara ketat hanya untuk tujuan pendidikan dan pembelajaran, serta harus digunakan secara bijak sesuai dengan peraturan akademik universitas[cite: 6].
