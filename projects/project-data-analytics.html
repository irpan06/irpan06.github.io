Data Job Analytics Platform

Mengubah data lowongan pekerjaan mentah menjadi wawasan bisnis skala produksi menggunakan arsitektur Medallion.

Python Google BigQuery dbt Looker Studio Jupyter

Latar Belakang & Tujuan

Proyek ini merupakan implementasi pipeline ELT (Extract, Load, Transform) end-to-end yang dirancang untuk mengubah data lowongan kerja mentah menjadi data warehouse analitik modern, serta menyajikan wawasan bisnis melalui dashboard interaktif[cite: 5]. Dataset komprehensif yang digunakan bersumber dari hasil kurasi Luke Barousse[cite: 4].

Tujuan utama proyek ini adalah merancang fondasi data menggunakan paradigma ELT, menerapkan pemodelan Star Schema dalam Medallion Architecture, mengotomatisasi transformasi dengan dbt, dan menghasilkan dashboard BI yang dinamis[cite: 5].

Pendekatan Teknis: Rekayasa Data

Dalam fase Rekayasa Data, saya mengadopsi arsitektur yang terpisah (decoupled architecture). Python murni digunakan sebagai alat tepercaya untuk ekstraksi dan pemuatan (ingestion) data operasional mentah, sementara beban kerja analitik berat (OLAP) diserahkan sepenuhnya ke Google BigQuery[cite: 4].

Data diproses melewati Medallion Architecture (Bronze untuk data mentah, Silver untuk standarisasi, dan Gold untuk agregasi)[cite: 4].

Tantangan Teknis & Solusi

  • Deduplikasi Berkecepatan Tinggi: Karena dataset scraped tidak memiliki primary key yang andal, saya mengimplementasikan metode hash integer 64-bit menggunakan fungsi FARM_FINGERPRINT() untuk melakukan deduplikasi yang cepat dan hemat memori[cite: 4].
  • Pemodelan Skema Star yang Rumit: Atribut keahlian yang awalnya berbentuk string array Python dipisahkan menggunakan fungsi bawaan BigQuery UNNEST(SPLIT()), lalu direstrukturisasi menjadi Star Schema menggunakan Bridge Table untuk menyelesaikan masalah relasi many-to-many tanpa menyebabkan redundansi[cite: 4].
  • Orkestrasi Skala Produksi: Seluruh proses transformasi logis dikelola secara modular oleh dbt, yang juga menangani pengujian kualitas data serta optimalisasi biaya komputasi melalui materialisasi inkremental[cite: 4].

Analitik & Wawasan Bisnis

Fase Analitik memanfaatkan data yang telah disempurnakan di lapisan Gold Layer (mart_gold) dari BigQuery[cite: 3]. Hal ini memastikan tingkat akurasi dan performa yang tinggi saat menyuplai data ke dashboard eksekutif interaktif yang dibangun dengan Looker Studio[cite: 3, 5].

Di luar pemantauan KPI standar, saya melakukan analisis mendalam secara terprogram menggunakan Jupyter Notebook dan SQL (seperti Window Functions dan CTE) untuk menjawab studi kasus bisnis spesifik[cite: 3, 5], di antaranya:

  • The Remote Work Premium: Menganalisis korelasi antara status bekerja dari rumah (WFH), ketersediaan asuransi kesehatan, dan rata-rata gaji yang ditawarkan[cite: 3, 5].
  • Tren Perekrutan Berbasis Keahlian: Mengevaluasi pergeseran tren pasar di mana persentase peran dengan bayaran tinggi kini mulai meninggalkan syarat wajib gelar universitas[cite: 3, 5].
  • Pemetaan Kuadran Valuasi Keahlian: Memetakan titik temu antara keahlian yang paling sering dicari di pasar dengan rentang kompensasi finansial tertinggi[cite: 3, 5].
