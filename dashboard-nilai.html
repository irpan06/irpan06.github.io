Latar Belakang & Tujuan

Proyek ini adalah aplikasi interaktif berbasis Streamlit yang dirancang untuk menganalisis transkrip mahasiswa di Universitas Airlangga (UNAIR)[cite: 5]. Aplikasi ini awalnya dikembangkan khusus untuk Program Studi Fisika, namun logika pencocokan kurikulumnya dapat dengan mudah diadaptasi untuk program studi atau universitas lain[cite: 5].

Tujuan utamanya adalah menyediakan dashboard komprehensif yang menampilkan visualisasi IPK dan IPS (Indeks Prestasi Semester), distribusi nilai per semester, pelacakan kemajuan SKS untuk mata kuliah wajib dan pilihan (KBK), serta daftar mata kuliah yang belum diselesaikan[cite: 5].

Pendekatan Teknis: Pemrosesan Data & Otomatisasi

Aplikasi ini dibangun menggunakan stack Python untuk pemrosesan data, visualisasi, dan otomatisasi yang tangguh[cite: 5]. Aplikasi ini memanfaatkan pustaka Requests dan BeautifulSoup untuk login ke portal akademik UNAIR dan melakukan scraping data transkrip secara mulus[cite: 5].

Setelah data diambil, Pandas menangani pembersihan transkrip dan perhitungan IPK/IPS, sementara Difflib (SequenceMatcher) digunakan untuk mencocokkan nama mata kuliah hasil scraping dengan kurikulum UNAIR yang disimpan dalam file Excel secara akurat[cite: 5].

Detail Implementasi

  • Scraping & Parsing: Data transkrip diambil menggunakan pustaka Requests dan diparsing secara terstruktur menggunakan BeautifulSoup[cite: 5].
  • Simulasi Interaktif: Mengintegrasikan st-aggrid untuk menyediakan tabel interaktif di mana pengguna dapat menyesuaikan nilai mereka guna menyimulasikan dan memprediksi hasil IPK di masa depan[cite: 5].
  • Kustomisasi Kurikulum: Logika pencocokan kurikulum bergantung pada file Excel (seperti mk_wajib.xlsx), membuat sistem ini sangat mudah beradaptasi untuk universitas lain hanya dengan mengganti file-file tersebut[cite: 5].

Fitur & Visualisasi

Lapisan presentasi dari dashboard ini berfokus pada wawasan visual interaktif dan kemampuan ekspor data:

  • Bagan Dinamis: Menggunakan Matplotlib dan Plotly untuk menghasilkan grafik distribusi nilai interaktif, bagan IPS, dan diagram donat IPK berdasarkan data yang telah diproses[cite: 5].
  • Ekspor Data: Mengintegrasikan OpenPyXL untuk memungkinkan pengguna mengekspor data transkrip yang telah diproses langsung ke dalam format Excel untuk pengarsipan pribadi[cite: 5].
  • Penerapan Cloud: Seluruh aplikasi di-hosting secara online dan dapat diakses oleh publik melalui Streamlit Cloud[cite: 5].
